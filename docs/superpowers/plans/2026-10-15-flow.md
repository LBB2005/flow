# Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Flow, a menu-bar macOS app. Hold a hotkey in any app and speak, and when you let go, cleaned-up text is pasted at the cursor. Everything runs locally and offline.

**Architecture:** A native Swift/SwiftUI menu bar app. A pure `HotkeyStateMachine` turns key events into actions. A `DictationCoordinator` runs record → transcribe (WhisperKit) → clean (Qwen3 via MLX Swift) → paste. Each stage sits behind a small protocol, so the coordinator is fully unit-tested with fakes. All UI constants live in `Theme.swift`, and a Debug-only UI Playground lets us iterate on the pill quickly.

**Tech Stack:** Swift 6, SwiftUI + AppKit, Swift Testing, XcodeGen, `xcodebuild`, WhisperKit (from `argmax-oss-swift`), MLX Swift LM 3.x, swift-huggingface, swift-transformers.

**Spec:** `docs/superpowers/specs/2026-10-15-flow-design.md`. Read it before starting any task.

## Global Constraints

- Project root: `~/code/flow`. Every command below runs from there.
- Platform: macOS 26.0 deployment target, Apple Silicon only (`ARCHS = arm64`). Dev machine has Xcode 27.0 and Swift 6.4.
- Swift 6 language mode (`SWIFT_VERSION = 6.0`). Tests use Swift Testing (`import Testing`, `@Test`, `#expect`), not XCTest.
- Bundle id `com.liamblackshawbrown.flow`. App name `Flow`. `LSUIElement = YES` (no Dock icon).
- App sandbox off. Hardened runtime off. Code signing identity `Flow Dev` (self-signed, created in Task 1). Fallback: `-` (ad-hoc).
- No network at runtime except model downloads. No telemetry. No paid APIs.
- Package pins (exact versions; all at least two weeks old on 2026-10-15):
  - `https://github.com/argmaxinc/argmax-oss-swift` **1.1.0**, product `WhisperKit`. This is WhisperKit's new home; `argmaxinc/WhisperKit` redirects there.
  - `https://github.com/ml-explore/mlx-swift-lm` **3.32.3**, products `MLXLLM`, `MLXLMCommon`, `MLXHuggingFace`
  - `https://github.com/huggingface/swift-huggingface` **0.11.0**, product `HuggingFace`
  - `https://github.com/huggingface/swift-transformers` **1.3.4**, product `Tokenizers`
- XcodeGen comes from Homebrew. `Flow.xcodeproj` is generated and git-ignored, so never edit it by hand. Change `project.yml` and run `make gen`.
- Default hotkey: **Right ⌥ held**. Hold threshold **0.3 s**. **Esc** cancels.
- Audio: **16 kHz mono Float32**. Max recording **5 minutes**.
- Whisper variants: default `large-v3-v20240930_626MB`, alternative `base`. Cleanup models: default `mlx-community/Qwen3-1.7B-4bit`, alternative `mlx-community/Qwen3-4B-4bit`. Qwen3 thinking is **disabled** (`enable_thinking: false`). Temperature **0**.
- Cleanup timeout **5 s**. Validator rejects output that is empty, longer than **1.5 × input + 50 chars**, starts with an assistant preamble not present in the input, or contains `<think>` tags. On any failure, the **raw transcript** is pasted.
- Keep-warm options: 2 min / **10 min (default)** / 30 min / Always.
- Pill copy (exact): `Listening`, `Thinking…`, `Cancelled`, `Didn't catch that`, `Copied, press ⌘V`. Errors: `Microphone unavailable`, `Transcription failed`, plus readiness messages from Task 18.
- Commits: use `scripts/commit "<message>" <paths…>` (created in Task 1). It appends the required trailer lines:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_018Cqj3JKViUBZc5E8FyCZHS`.
- Test commands: `make test` (all), `make test ONLY=<SuiteName>` (one suite). Opt-in real-model tests: `make test-models`.
- **Checkpoints marked 🛑 are hard stops.** Report to the user, and wait for their go-ahead or feedback before continuing.

## Review Focus

These are the inputs and failure modes the spec implies but no headline feature exercises. Each one has a pinning test in the task listed.

1. **Whisper hallucinating on silence:** holding the key without speaking makes Whisper emit `[BLANK_AUDIO]`, `(silence)`, `*coughs*` or `♪`. Expected: "Didn't catch that" and nothing pasted. Pinned in Task 4 (`TranscriptNormalizer`) and Task 7 (silent audio skips transcription entirely).
2. **Non-text clipboard contents:** an image or Finder file is on the clipboard when you dictate. Expected: it comes back intact after the paste. And if you copy something new during the restore delay, Flow doesn't overwrite it. Pinned in Task 10.
3. **⌥-click / ⌥-drag:** holding Right ⌥ for a mouse gesture (Finder, Figma, text selection). Expected: no dictation starts and the gesture works. Pinned in Task 3 (`otherInput` cancels) and Task 8 (mouse-down classified as `other`).
4. **Dictating an instruction or question to an LLM:** "can you write me a poem about cats". Expected: the cleaned *question* is pasted, never an answer. Pinned in Task 4 (validator preamble + length rules) and Task 19 (eval cases).
5. **Pressing the hotkey again while the last dictation is still processing.** Expected: ignored, with no second recording and no double paste. Pinned in Task 7.

- [ ] **Step 3: Create the self-signed "Flow Dev" code-signing identity**

macOS ties the Accessibility permission to the app's signature. A stable signing identity means the permission survives rebuilds.

`scripts/make-dev-cert.sh`:
```bash
#!/bin/bash
# Creates a self-signed code-signing identity called "Flow Dev" in the login keychain.
set -euo pipefail
NAME="Flow Dev"
KEYCHAIN="$HOME/Library/Keychains/login.keychain-db"
if security find-identity -v -p codesigning | grep -q "\"$NAME\""; then
  echo "✓ '$NAME' already exists"; exit 0
fi
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT
cat > "$TMP/cert.cnf" <<EOF
[req]
distinguished_name = dn
x509_extensions = ext
prompt = no
[dn]
CN = $NAME
[ext]
basicConstraints = critical,CA:false
keyUsage = critical,digitalSignature
extendedKeyUsage = critical,codeSigning
EOF
# /usr/bin/openssl is LibreSSL, whose PKCS#12 output the macOS keychain imports directly.
/usr/bin/openssl req -x509 -newkey rsa:2048 -nodes -days 3650 \
  -config "$TMP/cert.cnf" -keyout "$TMP/key.pem" -out "$TMP/cert.pem"
/usr/bin/openssl pkcs12 -export -inkey "$TMP/key.pem" -in "$TMP/cert.pem" \
  -name "$NAME" -out "$TMP/cert.p12" -passout pass:flowdev
security import "$TMP/cert.p12" -k "$KEYCHAIN" -P flowdev -T /usr/bin/codesign
# Marks the cert trusted for code signing. macOS shows a password dialog here.
security add-trusted-cert -p codeSign -k "$KEYCHAIN" "$TMP/cert.pem"
security find-identity -v -p codesigning | grep "$NAME"
```
Run: `chmod +x scripts/make-dev-cert.sh && scripts/make-dev-cert.sh`
Expected: the last line lists `"Flow Dev"`. **The user must approve a macOS password dialog.** Tell them before running.
If it fails: set `CODE_SIGN_IDENTITY: "-"` in `project.yml` (Step 4) and note it in the task report. The user will then need to re-grant Accessibility after rebuilds.

`Flow/Hotkey/Hotkey.swift`:
```swift
import CoreGraphics

/// A modifier key that can be held on its own as a push-to-talk hotkey.
enum ModifierKey: String, Codable, CaseIterable, Sendable {
    case rightOption, leftOption, rightCommand, rightControl, rightShift, function

    var keyCode: UInt16 {
        switch self {
        case .rightOption: 61
        case .leftOption: 58
        case .rightCommand: 54
        case .rightControl: 62
        case .rightShift: 60
        case .function: 63
        }
    }

    /// Device-dependent bit for this physical key in CGEventFlags / NSEvent.ModifierFlags raw values.
    var deviceFlagMask: UInt64 {
        switch self {
        case .rightOption: 0x40        // NX_DEVICERALTKEYMASK
        case .leftOption: 0x20         // NX_DEVICELALTKEYMASK
        case .rightCommand: 0x10       // NX_DEVICERCMDKEYMASK
        case .rightControl: 0x2000     // NX_DEVICERCTLKEYMASK
        case .rightShift: 0x04         // NX_DEVICERSHIFTKEYMASK
        case .function: 0x800000       // NX_SECONDARYFNMASK
        }
    }

    var displayName: String {
        switch self {
        case .rightOption: "Right ⌥"
        case .leftOption: "Left ⌥"
        case .rightCommand: "Right ⌘"
```

```swift
import Foundation

enum HotkeyInput: Equatable, Sendable {
    case hotkeyDown(at: TimeInterval)
    case hotkeyUp(at: TimeInterval)
    /// Any other key press or mouse click while the hotkey is engaged.
    case otherInput(at: TimeInterval)
    case escape(at: TimeInterval)
    /// Timer callback scheduled `holdThreshold` after `hotkeyDown`.
    case tick(at: TimeInterval)
}

enum CancelReason: Equatable, Sendable {
    case chord
    case escape
}

enum HotkeyAction: Equatable, Sendable {
    /// Key went down: start capturing audio, no UI yet.
    case begin
    /// Held past the threshold: show the pill.
    case confirm
    /// Released after a real hold: process the audio.
    case finish
    /// Released too quickly: drop the audio silently.
    case discard
    case cancel(CancelReason)
}

/// Pure push-to-talk logic. Knows nothing about CGEvents or timers.
struct HotkeyStateMachine: Sendable {
    static let holdThreshold: TimeInterval = 0.3

    enum Phase: Equatable, Sendable {
        case idle
        case pending(since: TimeInterval)
        case active
    }

    private(set) var phase: Phase = .idle

    var isEngaged: Bool { phase != .idle }

    mutating func handle(_ input: HotkeyInput) -> HotkeyAction? {
        switch input {
        case .hotkeyDown(let time):
            guard phase == .idle else { return nil }
            phase = .pending(since: time)
            return .begin

        case .tick(let time):
            guard case .pending(let since) = phase, time - since >= Self.holdThreshold else { return nil }
            phase = .active
            return .confirm

        case .hotkeyUp(let time):
            switch phase {
            case .idle:
                return nil
            case .pending(let since):
                phase = .idle
                return time - since >= Self.holdThreshold ? .finish : .discard
            case .active:
                phase = .idle
                return .finish
            }

        case .otherInput:
            guard isEngaged else { return nil }
            phase = .idle
            return .cancel(.chord)

        case .escape:
            guard isEngaged else { return nil }
            phase = .idle
            return .cancel(.escape)
        }
    }
}
```

```swift
import Foundation

/// Cleans Whisper's raw output before anything else sees it.
enum TranscriptNormalizer {
    static func normalize(_ raw: String) -> String {
        // [BLANK_AUDIO], [MUSIC] etc. are never speech: remove them everywhere.
        var text = raw.replacing(#/\[[^\]]*\]/#, with: "")
        text = text.replacing(#/[ \t]{2,}/#, with: " ")
            .trimmingCharacters(in: .whitespacesAndNewlines)

        // (silence), *coughs* and ♪ are only noise when nothing else was said.
        let speech = text.replacing(#/\([^)]*\)|\*[^*]*\*|♪/#, with: "")
            .trimmingCharacters(in: .whitespacesAndNewlines.union(.punctuationCharacters))
        return speech.isEmpty ? "" : text
    }
}
```

```swift
import Foundation

enum CleanupRejection: Equatable, Sendable {
    case empty
    case tooLong
    case assistantPreamble
    case thinkingTags
}

enum CleanupVerdict: Equatable, Sendable {
    case accept(String)
    case reject(CleanupRejection)
}

/// Decides whether the cleanup model's output is safe to paste (spec §6).
enum CleanupValidator {
    static let preambles = [
        "sure", "certainly", "of course", "absolutely", "here is", "here's",
        "okay, here", "i'd be happy", "i'm sorry", "as an ai",
    ]

    static func validate(input: String, output: String) -> CleanupVerdict {
        let cleaned = output.trimmingCharacters(in: .whitespacesAndNewlines)
        if cleaned.isEmpty { return .reject(.empty) }
        if cleaned.contains("<think>") || cleaned.contains("</think>") { return .reject(.thinkingTags) }
        if Double(cleaned.count) > 1.5 * Double(input.count) + 50 { return .reject(.tooLong) }

        let outLower = normalizeApostrophes(cleaned.lowercased())
        let inLower = normalizeApostrophes(input.lowercased())
        for preamble in preambles where outLower.hasPrefix(preamble) && !inLower.contains(preamble) {
            return .reject(.assistantPreamble)
        }
        return .accept(cleaned)
    }

    private static func normalizeApostrophes(_ text: String) -> String {
        text.replacingOccurrences(of: "\u{2019}", with: "'")
    }
}
```

```swift
/// Decides whether a recording contains anything worth transcribing.
/// Whisper hallucinates text on silence, so silent clips never reach it.
enum SilenceDetector {
    /// ≈ -40 dBFS. Laptop-mic room noise sits well below this; speech sits well above it.
    static let rmsThreshold: Float = 0.01

    static func isSilent(_ samples: [Float], sampleRate: Int = 16_000) -> Bool {
        guard samples.count >= sampleRate / 4 else { return true }
        let window = sampleRate / 10
        var start = 0
        while start < samples.count {
            let end = min(start + window, samples.count)
            var sum: Float = 0
            for index in start..<end { sum += samples[index] * samples[index] }
            if (sum / Float(end - start)).squareRoot() >= rmsThreshold { return false }
            start = end
        }
        return true
    }
}
```

```swift
import Foundation

struct TimeoutError: Error {}

/// Runs `operation`, but gives up after `timeout` even if the operation ignores
/// cancellation (MLX generation can't always be interrupted mid-token).
func withTimeout<T: Sendable>(
    _ timeout: Duration,
    operation: @escaping @Sendable () async throws -> T
) async throws -> T {
    try await withCheckedThrowingContinuation { continuation in
        let gate = ResumeOnce(continuation)
        let work = Task {
            do { gate.resume(with: .success(try await operation())) }
            catch { gate.resume(with: .failure(error)) }
        }
        Task {
            try? await Task.sleep(for: timeout)
            work.cancel()
            gate.resume(with: .failure(TimeoutError()))
        }
    }
}

private final class ResumeOnce<T: Sendable>: @unchecked Sendable {
    private let lock = NSLock()
    private var continuation: CheckedContinuation<T, Error>?

    init(_ continuation: CheckedContinuation<T, Error>) { self.continuation = continuation }

    func resume(with result: Result<T, Error>) {
        let pending: CheckedContinuation<T, Error>? = lock.withLock {
            defer { continuation = nil }
            return continuation
        }
        pending?.resume(with: result)
    }
}
```

```swift
import Foundation

/// Runs one dictation at a time: record → transcribe → clean → paste (spec §4–6).
@MainActor
final class DictationCoordinator {
    enum Phase: Equatable { case idle, recording, transcribing, cleaning, inserting }

    private(set) var phase: Phase = .idle
    /// The in-flight pipeline, exposed so tests can await it.
    private(set) var processing: Task<Void, Never>?

    var transcriber: Transcriber
    var cleaner: Cleaner
    /// Called after every dictation that reached processing (resets the keep-warm timer).
    var onDictationProcessed: (@MainActor () -> Void)?

    private let recorder: Recorder
    private let inserter: TextInserter
    private let pill: PillPresenter
    private let isCleanupEnabled: @MainActor () -> Bool
    private let blockedReason: @MainActor () -> String?
    private let cleanupTimeout: Duration

    init(
        recorder: Recorder,
        transcriber: Transcriber,
        cleaner: Cleaner,
        inserter: TextInserter,
        pill: PillPresenter,
        isCleanupEnabled: @escaping @MainActor () -> Bool,
        blockedReason: @escaping @MainActor () -> String? = { nil },
        cleanupTimeout: Duration = .seconds(5)
    ) {
        self.recorder = recorder
        self.transcriber = transcriber
        self.cleaner = cleaner
        self.inserter = inserter
        self.pill = pill
        self.isCleanupEnabled = isCleanupEnabled
        self.blockedReason = blockedReason
        self.cleanupTimeout = cleanupTimeout
        recorder.onMaxDurationReached = { [weak self] in
            Log.audio.notice("max recording length reached")
            self?.handle(.finish)
        }
    }

    func handle(_ action: HotkeyAction) {
        switch action {
        case .begin:
            guard phase == .idle else {
                Log.pipeline.debug("busy (\(String(describing: self.phase))), ignoring hotkey")
                return
            }
            if let reason = blockedReason() {
                pill.show(.error(reason))
                return
            }
            do {
                try recorder.start()
                phase = .recording
            } catch {
                Log.audio.error("recorder failed to start: \(error.localizedDescription)")
                pill.show(.error("Microphone unavailable"))
            }

        case .confirm:
            guard phase == .recording else { return }
            pill.show(.listening)

        case .discard:
            guard phase == .recording else { return }
            recorder.cancel()
            phase = .idle
            pill.hide()

        case .cancel(let reason):
            guard phase == .recording else { return }
            recorder.cancel()
            phase = .idle
            if reason == .escape { pill.show(.cancelled) } else { pill.hide() }

        case .finish:
            guard phase == .recording else { return }
            let samples = recorder.stop()
            phase = .transcribing
            pill.show(.thinking)
            processing = Task { await self.process(samples) }
        }
    }

    private func process(_ samples: [Float]) async {
        defer {
            phase = .idle
            onDictationProcessed?()
        }
        guard !SilenceDetector.isSilent(samples) else {
            pill.show(.noSpeech)
            return
        }

        let raw: String
        do {
            raw = TranscriptNormalizer.normalize(try await transcriber.transcribe(samples))
        } catch {
            Log.pipeline.error("transcription failed: \(error.localizedDescription)")
            pill.show(.error("Transcription failed"))
            return
        }
        guard !raw.isEmpty else {
            pill.show(.noSpeech)
            return
        }

        var text = raw
        if isCleanupEnabled() {
            phase = .cleaning
            text = await cleaned(raw) ?? raw
        }

        phase = .inserting
        let result = await inserter.insert(text)
        pill.show(result == .pasted ? .success : .copied)
    }

    /// Returns the validated cleanup, or nil to fall back to the raw transcript.
    private func cleaned(_ raw: String) async -> String? {
        let cleaner = self.cleaner
        do {
            let output = try await withTimeout(cleanupTimeout) { try await cleaner.clean(raw) }
            switch CleanupValidator.validate(input: raw, output: output) {
            case .accept(let text):
                return text
            case .reject(let reason):
                Log.pipeline.notice("cleanup rejected: \(String(describing: reason))")
                return nil
            }
        } catch {
            Log.pipeline.notice("cleanup failed: \(String(describing: error))")
            return nil
        }
    }
}
```

`Flow/Hotkey/HotkeyEventClassifier.swift`:
```swift
enum KeyEventKind: Sendable { case keyDown, keyUp, flagsChanged, mouseDown }

enum HotkeySignal: Equatable, Sendable { case down, up, other, escape }

struct ClassifiedEvent: Equatable, Sendable {
    var signal: HotkeySignal?
    /// True = drop the event so the frontmost app never sees it.
    var swallow: Bool

    static let pass = ClassifiedEvent(signal: nil, swallow: false)
}

/// Pure mapping from a raw keyboard/mouse event to a hotkey signal.
/// Kept separate from the CGEventTap so every case is unit-testable.
enum HotkeyEventClassifier {
    static func classify(
        hotkey: Hotkey, kind: KeyEventKind, keyCode: UInt16, flags: UInt64,
        isAutorepeat: Bool, engaged: Bool
    ) -> ClassifiedEvent {
        if kind == .mouseDown {
            return engaged ? .init(signal: .other, swallow: false) : .pass
        }
        switch hotkey {
        case .modifierOnly(let key):
            switch kind {
            case .flagsChanged:
                if keyCode == key.keyCode {
                    return .init(signal: key.isDown(flags: flags) ? .down : .up, swallow: false)
                }
                return engaged ? .init(signal: .other, swallow: false) : .pass
            case .keyDown:
                guard engaged else { return .pass }
                if keyCode == KeyNames.escape { return .init(signal: .escape, swallow: true) }
                return .init(signal: .other, swallow: false)
            case .keyUp, .mouseDown:
                return .pass
            }

        case .combo(let modifiers, let comboKey):
            switch kind {
            case .keyDown:
                if keyCode == comboKey && ModifierSet(eventFlags: flags) == modifiers {
                    return .init(signal: isAutorepeat ? nil : .down, swallow: true)
                }
                guard engaged else { return .pass }
                if keyCode == comboKey { return .init(signal: nil, swallow: true) }
                if keyCode == KeyNames.escape { return .init(signal: .escape, swallow: true) }
                return .init(signal: .other, swallow: false)
            case .keyUp:
                return engaged && keyCode == comboKey ? .init(signal: .up, swallow: true) : .pass
            case .flagsChanged, .mouseDown:
                return .pass
            }
        }
    }
}
```

```swift
import CoreGraphics
import Foundation

/// Installs a CGEventTap and turns raw events into `HotkeyAction`s.
/// Requires Accessibility permission (it is an active tap, so it can swallow Esc and combos).
@MainActor
final class HotkeyMonitor {
    var onAction: (@MainActor (HotkeyAction) -> Void)?
    private(set) var hotkey: Hotkey

    private var machine = HotkeyStateMachine()
    private var tap: CFMachPort?
    private var runLoopSource: CFRunLoopSource?
    private var isPaused = false
    private var tickTask: Task<Void, Never>?

    init(hotkey: Hotkey) {
        self.hotkey = hotkey
    }

    /// Returns false when the tap can't be created (Accessibility not granted yet).
    @discardableResult
    func start() -> Bool {
        if tap != nil { return true }
        let types: [CGEventType] = [.keyDown, .keyUp, .flagsChanged, .leftMouseDown, .rightMouseDown, .otherMouseDown]
        let mask = types.reduce(CGEventMask(0)) { $0 | (CGEventMask(1) << $1.rawValue) }
        guard let tap = CGEvent.tapCreate(
            tap: .cgSessionEventTap,
            place: .headInsertEventTap,
            options: .defaultTap,
            eventsOfInterest: mask,
            callback: hotkeyTapCallback,
            userInfo: Unmanaged.passUnretained(self).toOpaque()
        ) else {
            Log.hotkey.error("event tap creation failed (Accessibility not granted?)")
            return false
        }
        let source = CFMachPortCreateRunLoopSource(nil, tap, 0)
        CFRunLoopAddSource(CFRunLoopGetMain(), source, .commonModes)
        CGEvent.tapEnable(tap: tap, enable: true)
        self.tap = tap
        self.runLoopSource = source
        Log.hotkey.info("event tap installed for \(self.hotkey.displayName)")
        return true
    }

    func stop() {
        cancelIfEngaged()
        if let runLoopSource { CFRunLoopRemoveSource(CFRunLoopGetMain(), runLoopSource, .commonModes) }
        if let tap { CFMachPortInvalidate(tap) }
        tap = nil
        runLoopSource = nil
    }

    /// Applies a new shortcut immediately (no restart needed).
    func setHotkey(_ newHotkey: Hotkey) {
        cancelIfEngaged()
        hotkey = newHotkey
        Log.hotkey.info("hotkey changed to \(newHotkey.displayName)")
    }

    /// While paused every event passes straight through (used while recording a new shortcut).
    func setPaused(_ paused: Bool) {
        if paused { cancelIfEngaged() }
        isPaused = paused
    }

    // MARK: - Event handling (main thread)

    fileprivate func reenableTap() {
        if let tap { CGEvent.tapEnable(tap: tap, enable: true) }
        Log.hotkey.notice("event tap re-enabled after timeout")
    }

    /// Returns true if the event should be swallowed.
    fileprivate func process(kind: KeyEventKind, keyCode: UInt16, flags: UInt64, isAutorepeat: Bool) -> Bool {
        guard !isPaused else { return false }
        let result = HotkeyEventClassifier.classify(
            hotkey: hotkey, kind: kind, keyCode: keyCode, flags: flags,
            isAutorepeat: isAutorepeat, engaged: machine.isEngaged)
        if let signal = result.signal { send(signal) }
        return result.swallow
    }

    private func send(_ signal: HotkeySignal) {
        let now = ProcessInfo.processInfo.systemUptime
        let input: HotkeyInput = switch signal {
        case .down: .hotkeyDown(at: now)
        case .up: .hotkeyUp(at: now)
        case .other: .otherInput(at: now)
        case .escape: .escape(at: now)
        }
        dispatch(machine.handle(input))
        if case .pending = machine.phase { scheduleTick() } else { tickTask?.cancel() }
    }

    private func scheduleTick() {
        tickTask?.cancel()
        tickTask = Task { [weak self] in
            try? await Task.sleep(for: .seconds(HotkeyStateMachine.holdThreshold + 0.01))
            guard !Task.isCancelled, let self else { return }
            self.dispatch(self.machine.handle(.tick(at: ProcessInfo.processInfo.systemUptime)))
        }
    }

    private func cancelIfEngaged() {
        guard machine.isEngaged else { return }
        dispatch(machine.handle(.otherInput(at: ProcessInfo.processInfo.systemUptime)))
        tickTask?.cancel()
    }

    private func dispatch(_ action: HotkeyAction?) {
        guard let action else { return }
        Log.hotkey.debug("action: \(String(describing: action))")
        onAction?(action)
    }
}

/// C callback. The tap is added to the main run loop, so it always runs on the main thread.
private func hotkeyTapCallback(
    proxy: CGEventTapProxy, type: CGEventType, event: CGEvent, refcon: UnsafeMutableRawPointer?
) -> Unmanaged<CGEvent>? {
    guard let refcon else { return Unmanaged.passUnretained(event) }
    let monitor = Unmanaged<HotkeyMonitor>.fromOpaque(refcon).takeUnretainedValue()

    if type == .tapDisabledByTimeout || type == .tapDisabledByUserInput {
        MainActor.assumeIsolated { monitor.reenableTap() }
        return Unmanaged.passUnretained(event)
    }

    let kind: KeyEventKind
    switch type {
    case .keyDown: kind = .keyDown
    case .keyUp: kind = .keyUp
    case .flagsChanged: kind = .flagsChanged
    case .leftMouseDown, .rightMouseDown, .otherMouseDown: kind = .mouseDown
    default: return Unmanaged.passUnretained(event)
    }
    let keyCode = UInt16(truncatingIfNeeded: event.getIntegerValueField(.keyboardEventKeycode))
    let flags = event.flags.rawValue
    let isAutorepeat = event.getIntegerValueField(.keyboardEventAutorepeat) != 0

    let swallow = MainActor.assumeIsolated {
        monitor.process(kind: kind, keyCode: keyCode, flags: flags, isAutorepeat: isAutorepeat)
    }
    return swallow ? nil : Unmanaged.passUnretained(event)
}
```

```swift
/// Collects samples up to a hard cap (the 5-minute recording limit).
struct SampleAccumulator: Sendable {
    let maxSamples: Int
    private(set) var samples: [Float] = []

    init(maxSamples: Int) { self.maxSamples = maxSamples }

    var isFull: Bool { samples.count >= maxSamples }

    /// Appends up to the cap. Returns true only for the append that makes it full.
    mutating func append(_ newSamples: [Float]) -> Bool {
        guard !isFull else { return false }
        samples.append(contentsOf: newSamples.prefix(maxSamples - samples.count))
        return isFull
    }
}
```

```swift
import Foundation

enum AudioLevel {
    static let floorDB: Float = -50

    /// RMS of the chunk mapped to 0…1 across -50…0 dBFS, for the waveform.
    static func normalized(_ samples: [Float]) -> Float {
        guard !samples.isEmpty else { return 0 }
        let meanSquare = samples.reduce(0) { $0 + $1 * $1 } / Float(samples.count)
        guard meanSquare > 0 else { return 0 }
        let db = 10 * log10(meanSquare)
        return min(1, max(0, (db - floorDB) / -floorDB))
    }
}
```

```swift
import AVFoundation

/// Converts whatever the mic delivers into 16 kHz mono Float32.
/// Called on the audio thread, so it must not touch the main actor.
final class TapConverter: @unchecked Sendable {
    private let converter: AVAudioConverter
    private let outputFormat: AVAudioFormat

    init?(inputFormat: AVAudioFormat, sampleRate: Double = 16_000) {
        guard let output = AVAudioFormat(commonFormat: .pcmFormatFloat32, sampleRate: sampleRate,
                                         channels: 1, interleaved: false),
              let converter = AVAudioConverter(from: inputFormat, to: output) else { return nil }
        self.converter = converter
        self.outputFormat = output
    }

    func convert(_ buffer: AVAudioPCMBuffer) -> [Float] {
        let ratio = outputFormat.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 32
        guard let output = AVAudioPCMBuffer(pcmFormat: outputFormat, frameCapacity: capacity) else { return [] }

        nonisolated(unsafe) let source = buffer
        let consumed = Flag()
        var error: NSError?
        converter.convert(to: output, error: &error) { _, status in
            if consumed.value {
                status.pointee = .noDataNow
                return nil
            }
            consumed.value = true
            status.pointee = .haveData
            return source
        }
        guard error == nil, let channel = output.floatChannelData else { return [] }
        return Array(UnsafeBufferPointer(start: channel[0], count: Int(output.frameLength)))
    }

    private final class Flag: @unchecked Sendable { var value = false }
}
```

```swift
        var ids = [AudioDeviceID](repeating: 0, count: Int(size) / MemoryLayout<AudioDeviceID>.size)
        guard AudioObjectGetPropertyData(system, &address, 0, nil, &size, &ids) == noErr else { return [] }

    /// Points the engine's input at a specific device. Unknown UIDs (e.g. an unplugged
    /// headset) are ignored, so the engine keeps using the system default.
    static func setInputDevice(uid: String, on engine: AVAudioEngine) {
        guard var deviceID = inputDevices().first(where: { $0.uid == uid })?.id,
              let unit = engine.inputNode.audioUnit else {
            Log.audio.notice("input device \(uid) not found; using system default")
            return
        }
        let status = AudioUnitSetProperty(
            unit, kAudioOutputUnitProperty_CurrentDevice, kAudioUnitScope_Global, 0,
            &deviceID, UInt32(MemoryLayout<AudioDeviceID>.size))
        if status != noErr { Log.audio.error("failed to select input device: \(status)") }
    }

    private static func hasInput(_ id: AudioDeviceID) -> Bool {
        var address = AudioObjectPropertyAddress(
            mSelector: kAudioDevicePropertyStreams,
            mScope: kAudioObjectPropertyScopeInput,
            mElement: kAudioObjectPropertyElementMain)
        var size: UInt32 = 0
        return AudioObjectGetPropertyDataSize(id, &address, 0, nil, &size) == noErr && size > 0
    }

    private static func string(_ id: AudioDeviceID, _ selector: AudioObjectPropertySelector) -> String? {
        var address = AudioObjectPropertyAddress(
            mSelector: selector,
            mScope: kAudioObjectPropertyScopeGlobal,
            mElement: kAudioObjectPropertyElementMain)
        var value: Unmanaged<CFString>?
        var size = UInt32(MemoryLayout<Unmanaged<CFString>?>.size)
        guard AudioObjectGetPropertyData(id, &address, 0, nil, &size, &value) == noErr,
```

```swift
import AVFoundation

enum RecorderError: Error { case noInputDevice, unsupportedFormat }

@MainActor
final class AudioRecorder: Recorder {
    static let sampleRate = 16_000.0
    static let maxDuration: TimeInterval = 300

    var onMaxDurationReached: (@MainActor () -> Void)?
    /// Normalized level (0…1) of each incoming chunk, for the waveform.
    var onLevel: (@MainActor (Float) -> Void)?
    /// CoreAudio device UID; nil = system default.
    var preferredDeviceUID: String?

    private let engine = AVAudioEngine()
    private var accumulator = SampleAccumulator(maxSamples: Int(sampleRate * maxDuration))
    private var isRecording = false

    /// Pre-warms the engine at launch so recording starts faster.
    func prepare() { engine.prepare() }

    func start() throws {
        guard !isRecording else { return }
        if let uid = preferredDeviceUID { AudioDevices.setInputDevice(uid: uid, on: engine) }
        let input = engine.inputNode
        let format = input.outputFormat(forBus: 0)
        guard format.sampleRate > 0, format.channelCount > 0 else { throw RecorderError.noInputDevice }
        guard let converter = TapConverter(inputFormat: format, sampleRate: Self.sampleRate) else {
            throw RecorderError.unsupportedFormat
        }

        accumulator = SampleAccumulator(maxSamples: Int(Self.sampleRate * Self.maxDuration))
        input.installTap(onBus: 0, bufferSize: 1024, format: format,
                         block: Self.makeTapBlock(converter: converter) { [weak self] samples in
                             Task { @MainActor in self?.append(samples) }
                         })
        engine.prepare()
        do {
            try engine.start()
        } catch {
            input.removeTap(onBus: 0)
            throw error
        }
        isRecording = true
        Log.audio.debug("recording started (\(format.sampleRate) Hz, \(format.channelCount) ch)")
    }

    func stop() -> [Float] {
        teardown()
        Log.audio.debug("recording stopped: \(self.accumulator.samples.count) samples")
        return accumulator.samples
    }

    func cancel() {
        teardown()
        accumulator = SampleAccumulator(maxSamples: Int(Self.sampleRate * Self.maxDuration))
    }

    private func teardown() {
        guard isRecording else { return }
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        isRecording = false
    }

    private func append(_ samples: [Float]) {
        guard isRecording else { return }
        onLevel?(AudioLevel.normalized(samples))
        if accumulator.append(samples) { onMaxDurationReached?() }
    }

    /// Built in a nonisolated context so the block isn't inferred as @MainActor.
    /// It runs on the realtime audio thread.
    private nonisolated static func makeTapBlock(
        converter: TapConverter,
        sink: @escaping @Sendable ([Float]) -> Void
    ) -> AVAudioNodeTapBlock {
        { buffer, _ in sink(converter.convert(buffer)) }
    }
}
```

```swift
import Foundation

struct PasteboardSnapshot: Equatable, Sendable {
    /// One dictionary per pasteboard item: type identifier → data.
    var items: [[String: Data]]
}

@MainActor
protocol Pasteboard: AnyObject {
    var changeCount: Int { get }
    func snapshot() -> PasteboardSnapshot
    func restore(_ snapshot: PasteboardSnapshot)
    /// Replaces the contents with plain text and returns the new change count.
    func setString(_ string: String) -> Int
}

@MainActor
protocol KeySender: AnyObject {
    /// Posts ⌘V to the frontmost app.
    func sendPaste()
}

enum FocusState: Sendable {
    case editable
    case notEditable
    /// Accessibility couldn't tell (e.g. some Electron apps).
    case unknown
}

@MainActor
protocol FocusProbe: AnyObject {
    func focusState() -> FocusState
}

@MainActor
final class PasteboardInserter: TextInserter {
    static let restoreDelay: Duration = .milliseconds(400)

    private let pasteboard: Pasteboard
    private let keys: KeySender
    private let focus: FocusProbe
    private let sleep: @Sendable (Duration) async -> Void

    init(
        pasteboard: Pasteboard,
        keys: KeySender,
        focus: FocusProbe,
        sleep: @escaping @Sendable (Duration) async -> Void = { try? await Task.sleep(for: $0) }
    ) {
        self.pasteboard = pasteboard
        self.keys = keys
        self.focus = focus
        self.sleep = sleep
    }

    func insert(_ text: String) async -> InsertResult {
        let focusState = focus.focusState()
        let saved = pasteboard.snapshot()
        let ourChange = pasteboard.setString(text)

        guard focusState != .notEditable else {
            Log.insert.info("no editable field focused; left text on clipboard")
            return .copiedOnly
        }
        keys.sendPaste()
        guard focusState == .editable else {
            Log.insert.info("focus unknown; pasted and kept text on clipboard")
            return .pasted
        }
        await sleep(Self.restoreDelay)
        if pasteboard.changeCount == ourChange {
            pasteboard.restore(saved)
        } else {
            Log.insert.info("clipboard changed during paste; not restoring")
        }
        return .pasted
    }
}
```

```swift
import AppKit
import ApplicationServices

@MainActor
final class SystemPasteboard: Pasteboard {
    private let pasteboard = NSPasteboard.general

    var changeCount: Int { pasteboard.changeCount }

    func snapshot() -> PasteboardSnapshot {
        PasteboardSnapshot(items: (pasteboard.pasteboardItems ?? []).map { item in
            var entry: [String: Data] = [:]
            for type in item.types {
                if let data = item.data(forType: type) { entry[type.rawValue] = data }
            }
            return entry
        })
    }

    func restore(_ snapshot: PasteboardSnapshot) {
        pasteboard.clearContents()
        let items = snapshot.items.map { entry in
            let item = NSPasteboardItem()
            for (type, data) in entry { item.setData(data, forType: NSPasteboard.PasteboardType(type)) }
            return item
        }
        if !items.isEmpty { pasteboard.writeObjects(items) }
    }

    func setString(_ string: String) -> Int {
        pasteboard.clearContents()
        pasteboard.setString(string, forType: .string)
        // Tells clipboard managers (Raycast, Maccy, …) not to record this temporary value.
        pasteboard.setData(Data(), forType: NSPasteboard.PasteboardType("org.nspasteboard.TransientType"))
        return pasteboard.changeCount
    }
}

@MainActor
final class SystemKeySender: KeySender {
    func sendPaste() {
        let source = CGEventSource(stateID: .combinedSessionState)
        let vKey: CGKeyCode = 9
        let down = CGEvent(keyboardEventSource: source, virtualKey: vKey, keyDown: true)
        let up = CGEvent(keyboardEventSource: source, virtualKey: vKey, keyDown: false)
        // Explicit flags so a still-held hotkey modifier (e.g. ⌃ from ⌃Space) can't turn this into ⌃⌘V.
        down?.flags = .maskCommand
        up?.flags = .maskCommand
        down?.post(tap: .cghidEventTap)
        up?.post(tap: .cghidEventTap)
    }
}

@MainActor
final class AXFocusProbe: FocusProbe {
    private static let textRoles: Set<String> = ["AXTextField", "AXTextArea", "AXComboBox", "AXSearchField"]

    func focusState() -> FocusState {
        guard let app = NSWorkspace.shared.frontmostApplication else { return .unknown }
        let appElement = AXUIElementCreateApplication(app.processIdentifier)
        // Chromium/Electron apps (Cursor, VS Code, Slack) only expose their
        // accessibility tree once a client asks for it.
        AXUIElementSetAttributeValue(appElement, "AXManualAccessibility" as CFString, kCFBooleanTrue)

        var focused: CFTypeRef?
        switch AXUIElementCopyAttributeValue(appElement, kAXFocusedUIElementAttribute as CFString, &focused) {
        case .success:
            break
        case .noValue:
            return .notEditable
        default:
            return .unknown
        }
        guard let focused, CFGetTypeID(focused) == AXUIElementGetTypeID() else { return .unknown }
        let element = focused as! AXUIElement

        var role: CFTypeRef?
        if AXUIElementCopyAttributeValue(element, kAXRoleAttribute as CFString, &role) == .success,
           let role = role as? String, Self.textRoles.contains(role) {
            return .editable
        }
        for attribute in [kAXValueAttribute, kAXSelectedTextRangeAttribute] {
            var settable: DarwinBoolean = false
            if AXUIElementIsAttributeSettable(element, attribute as CFString, &settable) == .success, settable.boolValue {
                return .editable
            }
        }
        return .notEditable
    }
}
```

```swift
                try? await Task.sleep(for: .seconds(2))
            }
        }
    }
```

```swift
import AppKit
import SwiftUI

/// Hosts the pill in a borderless, non-activating panel that never steals focus.
@MainActor
final class OverlayController: PillPresenter {
    let model = PillModel()
    private var panel: NSPanel?
    private var hideTask: Task<Void, Never>?

    func show(_ state: PillState) {
        hideTask?.cancel()
        if state == .listening { model.resetLevels() }
        let wasVisible = panel?.isVisible ?? false
        withAnimation(wasVisible ? Theme.Motion.stateChange : Theme.Motion.appear) { model.state = state }

        let panel = self.panel ?? makePanel()
        if !wasVisible { position(panel) }
        panel.orderFrontRegardless()

        if let delay = state.autoHideAfter {
            hideTask = Task { [weak self] in
                try? await Task.sleep(for: delay)
                guard !Task.isCancelled else { return }
                self?.hide()
            }
        }
    }

    func hide() {
        hideTask?.cancel()
        panel?.orderOut(nil)
    }

    func push(level: Float) { model.push(level: level) }

    private func makePanel() -> NSPanel {
        let panel = NSPanel(
            contentRect: CGRect(origin: .zero, size: Theme.Pill.panelSize),
            styleMask: [.borderless, .nonactivatingPanel],
            backing: .buffered,
            defer: true)
        panel.isFloatingPanel = true
        panel.level = .statusBar
        panel.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]
        panel.backgroundColor = .clear
        panel.isOpaque = false
        panel.hasShadow = false
        panel.ignoresMouseEvents = true
        panel.hidesOnDeactivate = false
        panel.contentView = NSHostingView(rootView: PillView(model: model))
        self.panel = panel
        return panel
    }

    /// Bottom-centre of the screen the mouse is on (a good proxy for "the active screen").
    private func position(_ panel: NSPanel) {
        let mouse = NSEvent.mouseLocation
        let screen = NSScreen.screens.first { NSMouseInRect(mouse, $0.frame, false) } ?? NSScreen.main
        guard let frame = screen?.visibleFrame else { return }
        let size = Theme.Pill.panelSize
        let origin = CGPoint(x: frame.midX - size.width / 2, y: frame.minY + Theme.Pill.bottomOffset)
        panel.setFrame(CGRect(origin: origin, size: size), display: true)
    }
}
```

```swift
/// Restartable countdown used for the keep-warm window.
@MainActor
final class IdleTimer {
    private let sleep: @Sendable (Duration) async -> Void
    private var task: Task<Void, Never>?

    init(sleep: @escaping @Sendable (Duration) async -> Void = { try? await Task.sleep(for: $0) }) {
        self.sleep = sleep
    }

    /// Cancels any pending countdown and starts a new one. `nil` = never fire.
    func restart(after delay: Duration?, action: @escaping @MainActor () async -> Void) {
        task?.cancel()
        guard let delay else {
            task = nil
            return
        }
        task = Task { [sleep] in
            await sleep(delay)
            guard !Task.isCancelled else { return }
            await action()
        }
    }

    func cancel() {
        task?.cancel()
        task = nil
    }
}
```

```swift
import Foundation
import Observation

/// Owns model lifecycle: check → download → load → keep warm → unload when idle (spec §5).
@MainActor @Observable
final class ModelManager {
    enum Kind: CaseIterable, Sendable { case transcriber, cleaner }

    enum Status: Equatable, Sendable {
        case checking
        case notDownloaded
        case downloading(Double)
        case ready
        case failed(String)
    }

    private(set) var statuses: [Kind: Status] = [.transcriber: .checking, .cleaner: .checking]

    @ObservationIgnored private var backends: [Kind: any ModelBackend]
    @ObservationIgnored private var prepareTasks: [Kind: Task<Void, Never>] = [:]
    @ObservationIgnored private let idleTimer: IdleTimer
    @ObservationIgnored private let keepWarm: @MainActor () -> KeepWarm

    init(
        transcriber: any ModelBackend,
        cleaner: any ModelBackend,
        keepWarm: @escaping @MainActor () -> KeepWarm,
        idleTimer: IdleTimer = IdleTimer()
    ) {
        self.backends = [.transcriber: transcriber, .cleaner: cleaner]
        self.keepWarm = keepWarm
        self.idleTimer = idleTimer
    }

    func status(of kind: Kind) -> Status { statuses[kind] ?? .checking }

    func prepareAll() {
        for kind in Kind.allCases { prepare(kind) }
    }

    /// Downloads the model if needed, then loads it and starts the keep-warm countdown.
    @discardableResult
    func prepare(_ kind: Kind) -> Task<Void, Never> {
        prepareTasks[kind]?.cancel()
        guard let backend = backends[kind] else { return Task {} }
        let task = Task { [weak self] in
            guard let self else { return }
            self.statuses[kind] = .checking
            do {
                if !(await backend.isDownloaded()) {
                    self.statuses[kind] = .downloading(0)
                    Log.models.info("downloading \(backend.displayName)")
                    try await backend.download { fraction in
                        Task { @MainActor [weak self] in
                            guard let self, case .downloading = self.statuses[kind] else { return }
                            self.statuses[kind] = .downloading(fraction)
                        }
                    }
                }
                try Task.checkCancellation()
                try await backend.load()
                self.statuses[kind] = .ready
                self.touch()
                Log.models.info("\(backend.displayName) ready")
            } catch is CancellationError {
                return
            } catch {
                Log.models.error("\(backend.displayName) failed: \(error.localizedDescription)")
                self.statuses[kind] = .failed(error.localizedDescription)
            }
        }
        prepareTasks[kind] = task
        return task
    }

    /// Swaps in a different model (settings change): unloads the old one and prepares the new one.
    @discardableResult
    func replace(_ kind: Kind, with backend: any ModelBackend) -> Task<Void, Never> {
        let old = backends[kind]
        backends[kind] = backend
        Task { await old?.unload() }
        return prepare(kind)
    }

    /// Call after every dictation: restarts the keep-warm countdown.
    func touch() {
        idleTimer.restart(after: keepWarm().duration) { [weak self] in
            await self?.unloadAll()
        }
    }

    func unloadAll() async {
        Log.models.info("keep-warm expired; unloading models")
        for backend in backends.values { await backend.unload() }
    }
}
```

```swift
import Foundation
import WhisperKit

/// Local Whisper via WhisperKit (Core ML, Apple Neural Engine).
actor WhisperKitTranscriber: Transcriber, ModelBackend {
    nonisolated let displayName = "Speech recognition (Whisper)"

    private let variant: String
    private let downloadBase: URL
    private var pipe: WhisperKit?

    init(variant: String, downloadBase: URL = ModelPaths.root.appending(path: "whisper")) {
        self.variant = variant
        self.downloadBase = downloadBase
    }

    /// WhisperKit returns the folder it downloaded into; we remember it so later launches work offline.
    private var folderKey: String { "whisperFolder.\(variant)" }
    private var savedFolder: URL? {
        UserDefaults.standard.string(forKey: folderKey).map { URL(filePath: $0) }
    }

    func isDownloaded() -> Bool {
        guard let folder = savedFolder else { return false }
        return FileManager.default.fileExists(atPath: folder.appending(path: "AudioEncoder.mlmodelc").path)
    }

    func download(progress: @escaping @Sendable (Double) -> Void) async throws {
        let folder = try await WhisperKit.download(
            variant: variant,
            downloadBase: downloadBase,
            progressCallback: { progress($0.fractionCompleted) })
        UserDefaults.standard.set(folder.path, forKey: folderKey)
        Log.models.info("whisper downloaded to \(folder.path)")
    }

    func load() async throws {
        guard pipe == nil else { return }
        guard isDownloaded(), let folder = savedFolder else { throw ModelError.notDownloaded }
        let config = WhisperKitConfig(
            model: variant,
            modelFolder: folder.path,
            verbose: false,
            logLevel: .error,
            prewarm: true,
            load: true,
            download: false)
        pipe = try await WhisperKit(config)
    }

    func unload() async {
        nonisolated(unsafe) let current = pipe
        pipe = nil
        await current?.unloadModels()
    }

    func transcribe(_ samples: [Float]) async throws -> String {
        try await load()
        guard let pipe else { throw ModelError.notDownloaded }
        nonisolated(unsafe) let whisper = pipe
        let options = DecodingOptions(
            task: .transcribe,
            language: nil,
            temperature: 0,
            usePrefillPrompt: true,
            detectLanguage: true,
            skipSpecialTokens: true,
            withoutTimestamps: true)
        let results = try await whisper.transcribe(audioArray: samples, decodeOptions: options)
        return results.map(\.text).joined(separator: " ")
    }
}
```

```swift
import HuggingFace

/// Local cleanup with a small Qwen3 model on the GPU via MLX.
actor MLXCleaner: Cleaner, ModelBackend {
    nonisolated let displayName = "Cleanup model (Qwen3)"

    private let repoID: String
    private var container: ModelContainer?

    init(repoID: String) {
        self.repoID = repoID
    }

    private var folderKey: String { "llmFolder.\(repoID)" }
    private var savedFolder: URL? {
        UserDefaults.standard.string(forKey: folderKey).map { URL(filePath: $0) }
    }

    func isDownloaded() -> Bool {
        guard let folder = savedFolder,
              let files = try? FileManager.default.contentsOfDirectory(atPath: folder.path) else { return false }
        return files.contains("config.json") && files.contains { $0.hasSuffix(".safetensors") }
    }

    func download(progress: @escaping @Sendable (Double) -> Void) async throws {
        let downloader: any Downloader = #hubDownloader()
        let folder = try await downloader.download(
            id: repoID,
            revision: "main",
            matching: ["*.safetensors", "*.json", "*.jinja"],
            useLatest: false,
            progressHandler: { progress($0.fractionCompleted) })
        UserDefaults.standard.set(folder.path, forKey: folderKey)
        Log.models.info("cleanup model downloaded to \(folder.path)")
    }

    func load() async throws {
        guard container == nil else { return }
        guard isDownloaded(), let folder = savedFolder else { throw ModelError.notDownloaded }
        // Loading from a local directory never touches the network (offline after first download).
        let configuration = ModelConfiguration(directory: folder, extraEOSTokens: ["<|im_end|>"])
        container = try await LLMModelFactory.shared.loadContainer(
            from: #hubDownloader(),
            using: #huggingFaceTokenizerLoader(),
            configuration: configuration)
    }

    func unload() async {
        container = nil
    }

    func clean(_ transcript: String) async throws -> String {
        try await load()
        guard let container else { throw ModelError.notDownloaded }
        let session = ChatSession(
            container,
            instructions: CleanupPrompt.system,
            generateParameters: GenerateParameters(maxTokens: Self.maxTokens(for: transcript), temperature: 0),
            additionalContext: ["enable_thinking": false])
        var output = ""
        for try await chunk in session.streamResponse(to: CleanupPrompt.userMessage(for: transcript)) {
            try Task.checkCancellation()
            output += chunk
        }
        return Self.stripThinking(output)
    }

    /// Roughly 1 token ≈ 4 chars. Allows ~2× the input, capped at 2048.
    static func maxTokens(for transcript: String) -> Int {
        min(2048, transcript.count / 2 + 64)
    }

    /// Qwen3 can still emit an empty <think></think> block when thinking is disabled.
    static func stripThinking(_ text: String) -> String {
        text.replacing(#/<think>[\s\S]*?</think>/#, with: "")
            .trimmingCharacters(in: .whitespacesAndNewlines)
    }
}
```

```swift
/// Pure logic for the "Record shortcut" field. Feed it key events; it decides when a shortcut is complete.
struct ShortcutCapture {
    enum Result: Equatable {
        case captured(Hotkey)
        case cancelled
        case rejected(String)
    }

    /// Physical modifier key codes and their device-specific flag bits.
    private static let modifierMasks: [UInt16: UInt64] = [
        54: 0x10, 55: 0x08, 56: 0x02, 58: 0x20, 59: 0x01, 60: 0x04, 61: 0x40, 62: 0x2000, 63: 0x800000,
    ]
    private static let allModifierBits: UInt64 = modifierMasks.values.reduce(0, |)

    /// The one modifier pressed on its own so far, if any.
    private var candidate: UInt16?
    /// Set once anything else happens, so the lone-modifier gesture no longer counts.
    private var spoiled = false

    mutating func handleFlagsChanged(keyCode: UInt16, flags: UInt64) -> Result? {
        guard let mask = Self.modifierMasks[keyCode] else { return nil }
        let isDown = flags & mask != 0
        defer {
            if flags & Self.allModifierBits == 0 {
                candidate = nil
                spoiled = false
            }
        }
        if isDown {
            if candidate == nil && !spoiled { candidate = keyCode } else { spoiled = true }
            return nil
        }
        guard candidate == keyCode, !spoiled else { return nil }
        guard let key = ModifierKey(keyCode: keyCode) else {
            return .rejected("That key can't be used on its own. Try Right ⌥, Right ⌘, 🌐 Fn or a combo like ⌃Space.")
        }
        return .captured(.modifierOnly(key))
    }

    mutating func handleKeyDown(keyCode: UInt16, flags: UInt64) -> Result {
        spoiled = true
        let modifiers = ModifierSet(eventFlags: flags)
        if keyCode == KeyNames.escape && modifiers.isEmpty { return .cancelled }
        let hotkey = Hotkey.combo(modifiers: modifiers, keyCode: keyCode)
        if case .invalid(let message) = hotkey.validation { return .rejected(message) }
        return .captured(hotkey)
    }
}
```

```swift
import AppKit
import SwiftUI

/// Click, press a key or combo, done. Pauses the global hotkey while recording
/// so pressing the current hotkey here doesn't start a dictation.
struct HotkeyRecorderView: View {
    @Binding var hotkey: Hotkey
    var onRecordingChanged: (Bool) -> Void

    @State private var isRecording = false
    @State private var capture = ShortcutCapture()
    @State private var monitor: Any?
    @State private var message: String?

    var body: some View {
        VStack(alignment: .trailing, spacing: 6) {
            HStack {
                Button {
                    isRecording ? stopRecording() : startRecording()
                } label: {
                    Text(isRecording ? "Press a key or shortcut…" : hotkey.displayName)
                        .frame(minWidth: 170)
                }
                Button("Reset") {
                    hotkey = .default
                    message = nil
                }
                .disabled(hotkey == .default && !isRecording)
            }
            if let message {
                Text(message).font(.caption).foregroundStyle(.red)
            } else if case .warning(let warning) = hotkey.validation {
                Text(warning).font(.caption).foregroundStyle(.orange)
            }
        }
        .onDisappear { stopRecording() }
    }

    private func startRecording() {
        capture = ShortcutCapture()
        message = nil
        isRecording = true
        onRecordingChanged(true)
        monitor = NSEvent.addLocalMonitorForEvents(matching: [.keyDown, .flagsChanged]) { event in
            let keyCode = event.keyCode
            let flags = UInt64(event.modifierFlags.rawValue)
            let isKeyDown = event.type == .keyDown
            MainActor.assumeIsolated {
                let result = isKeyDown
                    ? capture.handleKeyDown(keyCode: keyCode, flags: flags)
                    : capture.handleFlagsChanged(keyCode: keyCode, flags: flags)
                if let result { finish(result) }
            }
            return nil // swallow everything while recording
        }
    }

    private func finish(_ result: ShortcutCapture.Result) {
        switch result {
        case .captured(let newHotkey):
            hotkey = newHotkey
            message = nil
            stopRecording()
        case .cancelled:
            stopRecording()
        case .rejected(let reason):
            message = reason
            capture = ShortcutCapture() // keep listening for another try
        }
    }

    private func stopRecording() {
        if let monitor { NSEvent.removeMonitor(monitor) }
        monitor = nil
        if isRecording { onRecordingChanged(false) }
        isRecording = false
    }
}
```

```markdown
# Flow

Hold a key, talk, let go: clean text appears wherever your cursor is. Built for writing LLM prompts fast.
Everything runs on your Mac. After a one-time model download (~1.6 GB) it works fully offline.

## Requirements
- Apple Silicon Mac, macOS 26+

## Build and run

    make run                   # generate the project, build, launch

First launch: allow **Microphone**, then menu bar icon → **Allow Accessibility** and switch Flow on.

## Use
- **Hold Right ⌥** (default), speak, release. The text is pasted at the cursor.
- **Esc** while holding cancels. A quick tap does nothing, so your normal ⌥ shortcuts still work.
- Menu bar → **Settings…** to change the shortcut, microphone, models, cleanup and how long models stay loaded.

## How it works
Hotkey (CGEventTap) → microphone (AVAudioEngine, 16 kHz) → Whisper large-v3 turbo (WhisperKit, Core ML)
→ cleanup with Qwen3 1.7B (MLX) → paste (clipboard + ⌘V, previous clipboard restored).
If cleanup fails or misbehaves, the raw transcript is pasted, so you never lose what you said.

    make test ONLY=HotkeyTests # one suite
    make test-models           # real Whisper + Qwen tests, including the 20-case cleanup eval
    make logs                  # live logs

All UI constants live in `Flow/Overlay/Theme.swift`. Debug builds have a menu bar **UI Playground**
that shows every pill state without dictating.

## Troubleshooting
- **Hotkey does nothing after a rebuild:** remove Flow from Privacy & Security → Accessibility, then add it again.
- **Using 🌐 Fn as the hotkey:** set System Settings → Keyboard → "Press 🌐 key to" → "Do Nothing".
- **Text not pasted in some app:** it's still on the clipboard; press ⌘V.
```
